# 你的农场键盘 · Your Farm Keyboard

> 一款电脑端搜狗输入法皮肤：**把每一次打字，变成在自己的小农场里种下与收获。**

![你的农场键盘 概念图](https://aka.doubaocdn.com/s/8Vu3h1r8sA)

- 作品名称：你的农场键盘（Your Farm Keyboard）
- 作者 / 设计者：黄一珊（Huang Yishan）
- 作品类型：电脑端搜狗输入法皮肤（静态版，H5 动态版规划中）
- 完成日期：2026-10-03

## 设计理念

核心创意是把“输入行为”重新诠释为“农场经营行为”：

- **字母键** = 种植 / 收获
- **Backspace** = 清理杂草
- **Enter** = 装箱 / 交付
- **Space** = 田间小路
- **123 / 符号** = 农场工具箱
- **中 / 英切换** = 切换田地

视觉风格为温暖治愈的轻 3D 桌面微缩农场：奶油白 + 浅草绿 + 暖木色，棕金细边框，
遵循“边缘丰富、中央克制”，保证输入可读性始终第一。

## 构建方式

搜狗 PC 皮肤以 `.ssf` 为扩展名（本质为 zip），根目录包含 `skin.ini` 与图片资源：

1. 由 `skin.ini` 指定 `Scheme_H1`（横排同窗）使用的主图与遮罩；
2. `pic_mask` 中黑色为透明、白色为显示；
3. 颜色值按 BGR（`0xBBGGRR`）字节序书写；
4. 将 `skin.ini`、`skin1.png`、`skin1_mask.png` 平铺打包为 zip 并改名为 `.ssf`；
5. 双击 `.ssf` 注册，即可在搜狗输入法中启用。
